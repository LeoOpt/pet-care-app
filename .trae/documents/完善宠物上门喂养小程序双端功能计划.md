# 宠物上门喂养小程序功能完善计划

## 一、项目背景与目标

基于市面上的宠物服务小程序调研（如小象优创、宠物家等），本项目需要实现完整的**双端小程序**：
- **下单者（用户端）**：需要预约服务的宠物主人
- **接单者（服务者端）**：提供上门喂养服务的喂养师

## 二、功能架构设计

### 2.1 用户角色切换机制

```
用户切换为接单者：
1. 个人中心 → 切换为服务者
2. 完成实名认证（姓名、身份证）
3. 提交资质证明（可选）
4. 设置服务信息（服务类型、价格、服务区域）
5. 审核通过后成为服务者

接单者切换回下单者：
1. 服务者中心 → 切换为用户
2. 保留服务者身份和设置
```

## 三、下单者（用户端）详细功能

### 3.1 首页
- **服务类型快速入口**：
  - 上门喂养
  - 遛狗服务
  - 宠物洗澡
  - 更多服务
- **搜索功能**：搜索喂养师或服务
- **热门喂养师推荐**：展示评分高、评价多的喂养师
- **筛选功能**：按距离、评分、价格、服务类型筛选

### 3.2 发布需求（下订单）流程

```
步骤1：选择宠物
├── 从已添加的宠物中选择
├── 支持多选（一只或多只宠物）
└── 显示宠物头像、名称、种类

步骤2：选择服务类型
├── 上门喂养（必选）
├── 遛狗服务
├── 宠物洗澡
├── 补充粮水
├── 清理卫生
└── 允许多选

步骤3：选择服务时间
├── 服务日期选择
├── 服务时间选择
└── 服务时长估算

步骤4：填写服务信息
├── 服务地址（支持地图选点）
├── 门牌号/详细地址
├── 门禁密码（如有）
├── 宠物喂养说明
└── 特殊注意事项

步骤5：选择喂养师（可选）
├── 系统自动匹配
├── 用户自选喂养师
└── 查看喂养师评价

步骤6：确认订单并支付
├── 费用明细展示
├── 优惠券选择
├── 使用余额
└── 微信支付
```

### 3.5 支付功能

```
支付流程：
1. 订单确认 → 生成待支付订单
2. 选择支付方式
   ├── 微信支付（优先）
   ├── 账户余额支付
   └── 优惠券抵扣
3. 输入支付密码（如使用余额）
4. 支付成功
5. 通知喂养师接单

退款流程：
├── 未接单：全额退款
├── 已接单：扣除已付金额的20%作为违约金
├── 服务中：扣除已完成部分费用
└── 已完成：不支持退款（特殊情况联系客服）
```

## 九、关键实现难点

1. **双端身份切换机制**
   - 难点：保持用户体验流畅
   - 解决方案：使用全局状态管理，清晰的界面区分
